# Kino TV — Tema Naruto Shippuden

Tema completo de Naruto Shippuden para **Kino TV** (apiVersion 18, Kino 0.9.81 o superior).
Naranja shinobi, negros sellados y marcos de chakra en toda la app, con logo vectorial propio.
El nombre **Kino TV** se mantiene intacto.

## Instalar

En Kino: **Ajustes ▸ Plugins**, y escribe:

```
Juan2Carlos7/kino-naruto-shippuden
```

O pega el enlace directo al manifiesto:

```
https://raw.githubusercontent.com/Juan2Carlos7/kino-naruto-shippuden/main/kino-plugin.json
```

## Incluye dos temas

- **Naruto Shippuden** — naranja shinobi sobre negro sellado, bordes suaves.
- **Chakra Kurama** — bermellón del zorro, formas más rectas.

Ambos incluyen los 45 tokens de color, forma, tipografía, elevación, movimiento y reproductor,
más logo vectorial (wordmark y marca) y valores ajustables desde Kino.

## Archivos

- `kino-plugin.json` — manifiesto del plugin.
- `plugin.js` — entry del plugin.

Al actualizar, sube siempre una `version` mayor (por ejemplo 1.0.0 → 1.0.1).
